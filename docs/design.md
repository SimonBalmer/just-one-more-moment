# My visual language

I use a simple retro terminal style throughout this project: red, white and black, with pixel lettering and monospaced technical labels.

| Element | My choice |
| --- | --- |
| Accent | Red `#BF1827` |
| Dark color | Near-black `#111111` |
| Background | White `#FFFFFF` |
| Secondary details | Neutral greys for hardware, outlines and depth |
| Titles in graphics | Custom uppercase pixel lettering |
| Technical labels | DejaVu Sans Mono, or a compatible mono typeface |
| Writing | First person, clear English, from my perspective |

I use red sparingly for titles, selected pins, power leads and the cursor motif. I keep labels and connection numbers legible before adding decoration. I distinguish signal leads with a white dash pattern over black so the diagram stays within the same color palette.

For SVG graphics I outline the lettering so it stays consistent when viewed on another computer. In PDFs I embed the mono font. GitHub controls the font and theme of ordinary Markdown text; my graphic banners, illustrations and document exports carry the custom visual style.

I describe my own build directly. When information is still missing, I write what I still need to add or confirm. I distinguish implemented behavior from ideas I plan to add.
