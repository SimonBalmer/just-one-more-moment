# Publication checklist

## Starting point

- [x] Confirm the title: **Just One More Moment**.
- [x] Create the public GitHub repository.
- [x] Capture the project concept and research question.
- [x] Record the supplied parts and pin assignment.
- [x] Record the builder-confirmed 12-pixel strip and Pi-powered NeoPixel setup.
- [x] Record USB webcam use and planned optional camera input.
- [x] Prepare the documentation folder structure.

## Inputs from the device

- [ ] Add working application code, startup scripts and non-secret configuration.
- [ ] Record OS, Python, dependency and exact local model versions.
- [ ] Record the webcam processing/inference pipeline.
- [ ] Add STL and editable CAD/STEP exports.
- [ ] Add real project photographs, including interior and assembly stages.
- [ ] Record exact toggle switch model and contact arrangement.
- [ ] Record diode type, placement, orientation and exact NeoPixel supply pins.
- [ ] Complete BOM quantities, fasteners and actual print settings/material usage.

## Build documentation

- [ ] Write reproducible software/model setup instructions.
- [ ] Write printing, mounting and assembly instructions.
- [ ] Add a circuit diagram matching the code and finished device.
- [ ] Document switch functions, startup, shutdown, reset and zero-countdown behavior.
- [ ] Document webcam operation and any image retention.
- [ ] Add troubleshooting based on observed issues.

## First complete version

- [ ] Review code/configuration for credentials and personal data before committing.
- [ ] Verify that wiring, software, photographs and guide agree.
- [ ] Test setup from a fresh Raspberry Pi installation when practical; record limitations.
- [ ] Add final author, software/model and AI-assistance credits.
- [ ] Choose and add project licenses for code, mechanical files and documentation.
- [ ] Add a project photograph and short demo video/link.
- [ ] Identify a tested version for submission and future reproduction.
